⚠️ Before Powering On

  • Coil connectors MUST be unplugged from original board
  • ESP32 powered via USB (NOT from 48V rail)
  • Double-check MBR30100CT center pin goes to +48V
  • Verify chassis ground is connected to your ground rail
  • Flash ESPHome config before installing in Hydrow

✓ Test Sequence

  • 1. Power on ESP32 via USB (no 48V yet) — display should show "HYDROW DRAG 0%"
  • 2. Turn pot — display should update percentage
  • 3. Connect to Home Assistant — verify slider works
  • 4. Power on Hydrow — 48V now live
  • 5. Set drag to 0% — spin flywheel, should be free
  • 6. Increase drag slowly — feel resistance increase

💡 How It Works

The +48V feeds through both coils constantly. Your MOSFETs control the return path to ground. When the MOSFET is OFF, no current flows and there's no magnetic drag. When ON, current flows through the coil creating an electromagnetic field that resists the flywheel. PWM duty cycle controls how much average current flows = adjustable drag.
